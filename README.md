A beginner-friendly analysis of Delhi Metro trip and fare data. The current
script uses only **NumPy** and **pandas**; it does not use a machine-learning
library.

## What the script does

The script reads the trip data and:

1. Shows the dataset's size, columns, missing values, duplicates, and basic
   statistics.
2. Compares fares by ticket type, peak hour, airport express, interchange count,
   and line.
3. Groups trips into distance ranges and summarizes the busiest routes.
4. Estimates a trip's fare by averaging fares from trips with the same distance
   range, ticket type, peak-hour status, and airport-express status.
5. Saves the trip data with estimates and a summary by metro line.

This is a simple, explainable example rather than a trained prediction model.
The printed average difference is calculated using the same trips that formed
the averages, so it is **not** a measure of how well the estimate works on new
trips.

## Project structure

```text
data/
  dmrc_fare_prediction_cleaned.csv   # Clean input dataset
  processed/
    dmrc_fare_results.csv            # Trips with estimated fares
reports/
  line_summary.csv                   # Summary by corridor line (generated by the script)
  model_comparison.csv               # Existing report from an earlier analysis
  feature_importance.csv             # Existing report from an earlier analysis
  test_predictions.csv               # Existing report from an earlier analysis
src/
  dmrc_fare_prediction.py            # NumPy and pandas analysis
requirements.txt
```

The current script updates `data/processed/dmrc_fare_results.csv` and
`reports/line_summary.csv`. It does not update the three earlier-analysis
reports.

## Setup

Install the two required packages:

```powershell
python -m pip install -r requirements.txt
```

## Run

From the project root:

```powershell
python src/dmrc_fare_prediction.py
```

Run the command from the project root. The script reads the input CSV from
`data/` and writes its results to `data/processed/` and `reports/`.
