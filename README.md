# 🚇 DMRC Fare Prediction

A Python project that analyzes Delhi Metro (DMRC) route data and estimates ticket fares based on travel distance and station details.

I created this project in **VS Code** using **NumPy** and **Pandas**.

---

### 🛠️ Tools & Libraries Used
* **Language:** Python
* **Libraries:** NumPy, Pandas
* **Editor:** VS Code
* **Data Source:** Kaggle (DMRC Dataset)

---

### ⚙️ What This Project Does
1. **Loads Data:** Reads the raw DMRC dataset downloaded from Kaggle using Pandas.
2. **Data Cleaning:** Handles missing/duplicate values and formats station and distance columns.
3. **Fare Calculation:** Uses NumPy and Pandas logic to filter routes and calculate/estimate ticket fares.

---

### 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder in **VS Code**.
3. Make sure `numpy` and `pandas` are installed (`pip install numpy pandas`).
4. Run the Python script to view the cleaned data and fare results.
